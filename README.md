# Chaz McKinney

Personal site for Chaz McKinney — software engineer, husband, father, and maker of ScriptWorks, Deseret Alphabet tools, and everyday apps.

Built with the same Vite + React 19 + TypeScript stack as [the-baybayin-project](https://github.com/cmckinney-59/the-baybayin-project).

## Develop

```bash
npm install
npm run dev
```

Open `http://localhost:5173/chaz-mckinney/` (hash routes, e.g. `#/projects`).

## Build & deploy

```bash
npm run build
npm run deploy
```
